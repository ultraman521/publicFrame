# PublicFrame → 可用的 Kotlin 公共脚手架：重写计划

## 目标形态

把项目重写为一个**可构建、可复用的现代 Kotlin 脚手架**：`framework`（脚手架库）+ `app`（示例应用）双模块，删除 `mvvmhabit`。技术栈：AndroidX + AGP 8.x + Kotlin 2.x + ViewBinding + 协程/Flow + Retrofit(suspend) + OkHttp 4 + Coil，Gradle Kotlin DSL + version catalog。

依据（已探明）：app 实际只用了 mvvmhabit 的 9 个类（KLog、AppManager、Utils、BaseViewModel/BaseModel、CloseUtils、日志拦截器、BuildConfig），全部低成本重写；真正通用的存量只有网络链路结构、MultiStateView、Toast/Loading；其余（RxBus、DataBinding 绑定适配器、下载栈、Fresco、QMUI shadowlayout、死工具类）未被任何代码引用，直接删除。

## 实施步骤

### 1. Git 快照 + 环境探测
- `git add -A && git commit` 提交现状快照（用户已确认）。
- 检测 `java -version` / `JAVA_HOME` / Android SDK（`local.properties`、`ANDROID_HOME`、已装 platforms）。据此定版本组合：JDK 17 → AGP 8.x；只有 JDK 11 → 降级 AGP 7.4 + Gradle 7.5；若 SDK 缺失则创建 `local.properties` 或报告阻塞。

### 2. 清理旧物
- 删除：`mvvmhabit/`、`publicFrame-prepared.zip`、`guagua.iml`、app 中全部业务死代码（BasicInterceptor、fresco/、shadowlayout/、download/、DataCleanManager、FileInfoUtils、ImgUtils、RxUtils、XOutdatedUtils、ShellUtils、RefreshStatus 等已探明的 B 类清单）。
- 更新 `.gitignore`。

### 3. 重写构建系统（Kotlin DSL + version catalog）
- `settings.gradle.kts`：只含 `:app`、`:framework`；仓库 mavenCentral + google。
- `gradle/libs.versions.toml`：统一管理版本（Kotlin、AGP、coroutines、lifecycle、retrofit、okhttp、coil、gson 等，实施时按环境锁定具体最新稳定版）。
- 根/模块 `build.gradle.kts`、`gradle.properties`（AndroidX、内存参数）、`gradle-wrapper.properties` 升级到配套 Gradle 8.x。
- app：compileSdk 35、minSdk 21、targetSdk 35、ViewBinding 开、DataBinding 关、包名/ applicationId 改为 `com.publicframe.demo`。

### 4. 重写 framework 模块（Kotlin，`com.publicframe.framework`）
- **入口**：保留增强 `PublicFrame`（initialize + appContext 访问）、`FrameworkConfiguration`（apiBaseUrl/enableLogging/cacheSize/超时）。
- **网络**：`ApiClient`（按配置惰性构建 OkHttp+Retrofit 单例：日志拦截器、缓存、公共头拦截器、Gson）；`ApiResponse<T>`（code/msg/data 信封 + isOk）；`errorOf(Throwable)` 异常映射（融合旧 ExceptionHandle 与 NewDefaultObserver 的错误分类）；可选的域名切换（OkHttp Interceptor 实现，替代 retrofit-url-manager）。
- **基类**：`BaseActivity<VB>` / `BaseFragment<VB>`（ViewBinding 泛型inflate + UiState 订阅 + loading/错误提示钩子）、`BaseViewModel`（viewModelScope 封装，把请求映射为 UiState 流）。
- **状态**：`UiState`（Loading/Content/Empty/Error+retry）+ 迁移 `MultiStateView`（Java→Kotlin 移植，配套 attrs/布局）。
- **工具**：`FrameLog`（受 enableLogging 门控）、`ToastUtils`（主线程安全简版）、`SPUtils` 简版、像素换算；最小化 `CrashHandler`（未捕获异常写日志文件）。
- consumer proguard 规则 + 一个 `FrameworkConfiguration` 校验的单元测试。

### 5. 重写 app 示例模块（`com.publicframe.demo`）
- `DemoApplication`：只调 `PublicFrame.initialize(this, FrameworkConfiguration(...))`。
- `MainActivity` + `MainViewModel`：ViewBinding + MultiStateView 演示 UiState 全状态切换，附一个可开关的示例 Retrofit suspend 调用模板（默认离线安全）。
- 资源清理：strings/styles/colors 去业务化，删除孤儿 attrs（ClearEditText/EasyTitleBar），保留启动图标。

### 6. 验证与收尾
- `gradlew :app:assembleDebug`、`gradlew test` 通过（依赖网络下载 Gradle 发行版与依赖）。
- 更新 `README.md` / `README.en.md`：新架构说明、接入步骤（initialize → 配 apiBaseUrl → 继承基类）、模块清单。
- 改造后不主动 commit（快照除外），完成后汇报。

## 风险
- JDK/SDK 状况未知（规划期无法执行命令），步骤 1 首先探测并选择降级方案或报告阻塞。
- 依赖需联网下载；若被代理阻断则报告。
- AGP/Kotlin 具体版本在实施时锁定，以环境实际可用的最新稳定版为准。
